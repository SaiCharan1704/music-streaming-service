## 🎧 What is Rythm?

**Rythm** is a fully-featured, browser-based music streaming application built with pure **HTML, CSS, and JavaScript** — no frameworks, no dependencies, just raw web power. Inspired by Spotify's design language and packed with every feature a modern music app needs, Rythm delivers a seamless, beautiful listening experience right in your browser.

> 🚀 **No installation. No account needed. Just open and play.**

## 🚀 Getting Started

### Option 1 — Open Directly (Zero Setup)

```bash
# Just open in your browser!
open index.html
# or double-click index.html in your file explorer
```

### Option 2 — Live Server (Recommended)

```bash
# 1️⃣  Clone the repository
git clone https://github.com/<your-username>/rythm.git
cd rythm

# 2️⃣  Open with Live Server (VS Code extension)
#     Right-click index.html → "Open with Live Server"

# 3️⃣  Or use Python's built-in server
python -m http.server 3000
# Then open → http://localhost:3000
```
